# FC Trade Manager — Documentação

[English](README.md)

Repositório central destinado à documentação técnica, especificações funcionais, arquitetura de sistema e artefatos de Garantia de Qualidade (QA) do projeto **FC Trade Manager**.

---

## 📋 Visão Geral

O **FC Trade Manager** é uma plataforma orientada a dados voltada para o rastreamento de mercado, análise de negociações e gerenciamento de elenco/ativos no modo Ultimate Team. Este repositório concentra o planejamento e a rastreabilidade do ciclo de vida do desenvolvimento (SDLC).
